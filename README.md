# ChurnMind AI

## Intelligent Customer Analytics Agent

ChurnMind AI is a machine learning-based customer analytics application designed to analyze customer data and predict customer churn. The application provides data-driven insights through an interactive and user-friendly interface.

## Key Features

- Customer churn prediction using Machine Learning
- Interactive analytics dashboard
- Customer data analysis and visualization
- AI-driven insights
- User-friendly Streamlit interface

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning
- Jupyter Notebook

## Dataset

The project uses the Telco Customer Churn dataset for customer analysis and churn prediction.

## Project Purpose

The objective of this project is to demonstrate how machine learning and data analytics can be used to identify customers who may be at risk of leaving a service and provide meaningful insights from customer data.
